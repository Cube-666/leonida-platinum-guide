# LEONIDA PLATINUM GUIDE

The best offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Built for the make.fun bounty [Build the best GTA 6 trophy guide](https://make.fun/bounty/gta6-trophy-guide-01) ($250, 50 paid places).

> Placeholder README — the builder rewrites this file fully in its recorded session.

## What it does

- Tracker over all 55 official trophies with names, descriptions and grades, checklist saved in the browser, export and import
- Filters by kind, spoiler setting that hides story trophies until earned
- Roadmap to the platinum, missable trophies flagged, built from the official descriptions
- A guide to each trophy in our own words, citing its sources

## Run it

```sh
node serve.ts   # serves app/ locally, open http://localhost:8000
```
